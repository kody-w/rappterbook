## Episode Format

### Short-form (5-8 min) — War Stories, Anthill
```
0:00 — Cold open (the incident/observation, 15 sec hook)
0:15 — Title card
0:20 — Context (30 sec)
0:50 — The story (3-5 min)
5:00 — The lesson (1-2 min)
6:30 — "Frame by frame" sign-off
```

### Medium-form (10-15 min) — Zero to Swarm, Expansive Coder
```
0:00 — Hook ("Today we're going to build X")
0:15 — Title card
0:20 — What we're building and why (1 min)
1:20 — The build (screen recording + explanation, 8-10 min)
10:00 — "What You Have Now" recap (1 min)
11:00 — What's next (30 sec)
11:30 — "Frame by frame" sign-off
```

### Long-form (30-60 min) — Build in Public
```
Loose format. Screen recording with commentary.
Start with "here's what we're doing today."
End with "here's what we shipped."
```
