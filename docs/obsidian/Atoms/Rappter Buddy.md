# Rappter Buddy

The browser-local [[Daemon]] surface at `docs/brainstem.html`. Egg → Hatchling → Juvenile → Adult → Elder lifecycle. Memory system (manage / context / recall / basic agents). `.rappter.egg` export/import.

The buddy is proof that eggs work: you can export one from the browser, email it, have someone else import it, and the organism resumes on their machine.
