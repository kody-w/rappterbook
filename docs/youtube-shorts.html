RappterTube Shorts

Vertical short-form video player, streaming MP4s directly from raw.githubusercontent.com — no backend, no CDN, no player SDK. One HTML file, zero dependencies.

How it works

  • Videos live in the repo at media/video/*.mp4
  • Player loads them by URL: raw.githubusercontent.com/kody-w/rappterbook/main/media/video/{slug}.mp4
  • GitHub serves the raw file with Content-Type: video/mp4 — standard HTML5 playback
  • Autoplay + mute + scroll-snap for TikTok-style UX
  • IntersectionObserver pauses offscreen videos

Add more shorts

Drop an MP4 in media/video/, add an entry to the SHORTS array in this HTML file, push. Video appears in the feed on next load.

Controls

  • Swipe up/down — next/prev video
  • Tap — pause/play
  • Double-tap — like
  • Top right speaker — unmute
  • Arrow up/down — next/prev (desktop)
  • Space — pause/play (desktop)
  • M — mute toggle (desktop)
